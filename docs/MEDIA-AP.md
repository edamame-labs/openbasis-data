# Direct AP state legislative calls

`tools/temporal/media_ap.py` parses the Associated Press's public live state dictionaries for November 3, 2026. Regional catalogs partition all 50 states into 100 exact metadata/progress URLs. They are media publications, separate from government results and legal certification.

The endpoint pattern is derived from observed AP application code rather than guessed: a [Spotlight PA results page](https://www.spotlightpa.org/news/2026/11/pennsylvania-election-results-2026-elections/) embeds [AP layout 37083](https://interactives.apelections.org/election-results/customers/layouts/organization-layouts/published/124213/37083.html). That layout references [layoutClient.js](https://interactives.apelections.org/election-results/assets/microsite/layoutClient.js), which selects [cycle-2026/remoteEntry.js](https://interactives.apelections.org/election-results/assets/cycle-2026/remoteEntry.js). The remote manifest identifies the visualization and result-card chunks. `ResultsCardGrid` constructs the dated `results/races/{state}/metadata.json` and `progress.json` paths under AP's live-data prefix. Its candidate code recognizes `winner: X` and labels `calledAt` as an AP call time. All five supporting application/layout observations are retained; changing a pinned chunk requires review.

For example, Pennsylvania's exact [metadata](https://interactives.apelections.org/election-results/data-live/2026-11-03/results/races/PA/metadata.json) and [progress](https://interactives.apelections.org/election-results/data-live/2026-11-03/results/races/PA/progress.json) publications contain federal, gubernatorial and state legislative races. This adapter selects only office `Y` (House, Assembly or Delegates) and `Z` (Senate or Nebraska Legislature). Same-day special primaries are excluded; general and explicitly special general-election races remain distinct by AP race ID. An absent legislative row does not prove that an office was off the ballot.

Every designation requires an explicit candidate `winner: X`; `R` runoff markers, estimated reporting percentages, zero-vote uncontested candidate lists and the largest vote count do not create calls. A named uncontested winner is accepted when AP explicitly marks that candidate `X`, and its outcome type remains distinct. Certification is not inferred from an AP flag.

The parser joins candidate details only by the exact candidate ID inside that same AP race. It preserves first/middle/last/suffix source components, party labels, race IDs, source observation IDs and JSON pointers. A call retains its supplied timezone-qualified timestamp. Metadata and progress are separate observations and are not asserted to be atomic.

Multiwinner races produce one designation per marked candidate, including partial slates. Vermont's Caledonia-3 can have one marked candidate while the publisher still says `Too Early to Call`; that individual call is retained without declaring every seat resolved. New Hampshire's Carroll District 1 retains all three marked candidates. `numWinners` is used only when directly supplied. Named districts remain named: AP `seatNum` 515 is a display code, not a replacement for Caledonia-3. `censusDistrict` and `seatNum` are retained as raw publisher fields, never invented Census GEOIDs. Washington's exact `District 1 - Position 2` label supplies district 1 and a separate position 2, while the full seat label remains visible.

Initial Northeast observations, acquired with ordinary `Mozilla/5.0` HTTP headers at `2026-11-05T06:27:55Z`–`06:27:56Z`, contain 1,649 legislative contests and 1,605 explicitly marked candidates across the assigned eleven-state catalogs. Multiple winners mean these two counts describe different units. New Jersey's observed dictionary has no selected legislative rows; that is recorded as an observation limit. The adapter retains original gzip-encoded HTTP bytes, checksums and actual response-completion times. Decompression is only a parsing step.
