# State-level media race calls

`tools/temporal/media_state.py` collects [NPR's 2026 governor dashboard](https://apps.npr.org/2026-election-results/governors.html), its public application script, and the exact script-linked [governor JSON](https://apps.npr.org/2026-election-results/data/gov.json). NPR explicitly attributes these election results to the Associated Press. The application displays a candidate's `winner === "X"` as a winner icon and `winnerDateTime` as “Winner called.” Original HTTP bytes, including gzip compression, remain archived with request URLs, actual observation timestamps and SHA-256 hashes.

The observed governor feed contains 36 distinct state races: 34 have an explicit AP call, while Alaska and Kansas remain uncalled in that observation. The parser requires candidate `winner: "X"`, contest `called: true`, and `raceCallStatus: "Called"` together. Test data, wrong office/type, duplicate state races, inconsistent flags and multiple governor winners fail closed. Vote totals, percentages, reporting completeness, candidate order and poll ratings never establish a call. Runoff flags are not winning calls.

Records use `designationStatus: media-called-winner`, `callingOrganization: Associated Press`, and `carryingOrganization: NPR`. Publisher candidate/race identifiers, first/last name fields, party label, raw call time, publisher update milliseconds, exact JSON pointers and observation references are retained. These media identifiers remain independent from official candidate/person identifiers. Names are not fuzzily merged. Certification, legal service and official government membership remain separate and unestablished.

`raceStatuses` retains all 36 validated governor races, including uncalled races. The publisher's `General` type is preserved. A separate special-election flag is unknown unless explicitly supplied; missing flags never become `false`. States absent from this feed remain uncollected rather than inferred off-ballot.

MPR News's directly linked election application exposes AP-sourced Minnesota state legislative APIs for 134 House and 67 Senate races. The observed feed explicitly marks 132 House and 63 Senate candidates with `winner: true`; six races remain uncalled. Each race must declare `source: ap`, office `Y` or `Z`, a unique district, and the correct candidate election epoch. MPR's script renders the boolean winner flag as a checkmark. Candidate identifiers, name/party, exact JSON pointers and publisher update times are retained. `lastUpdated` is not a call timestamp, so call time remains unknown. Publisher race IDs are not provided; labels and adapter-scoped observation IDs are retained without inventing publisher IDs.

Candidate-level state legislative calls outside Minnesota remain explicitly pending, without substituting chamber-control stories, projected majorities, or vote leaders. This is a coverage gap, not a complete national state legislative call dataset. Nebraska's actual unicameral ballot universe requires its separate official reference; generic pending audit rows make no second-chamber election assertion.

Run `.venv-geo/bin/python -m unittest discover -s tools -p 'test_temporal_media_state.py'`. `collect(fetch, offline=True)` preserves source epochs and never refreshes observation times during replay.
