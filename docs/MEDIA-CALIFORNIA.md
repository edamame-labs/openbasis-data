# California AP legislative card observations

`tools/temporal/media_california.py` extracts race status and explicit AP calls from preserved browser accessibility trees of the public AP results embeds linked by CalMatters. The source catalog binds the [State Senate cards](https://interactives.apelections.org/election-results/customers/layouts/organization-layouts/published/117697/38146.html) and [State Assembly cards](https://interactives.apelections.org/election-results/customers/layouts/organization-layouts/published/117697/38133.html) to distinct media source identifiers.

The acquired Senate tree contains 20 even-numbered district cards, with nine explicit calls. Its exact accessibility-tree bytes have SHA-256 `4fb3cff248e232db4c2f35693a8f8498d49f85a02ff0baeb0b5f8c8619b3152b`. The observation timestamp, `2026-11-05T05:31:26Z`, comes from the clock immediately after the browser accessibility capture. Acquisition metadata states that the tree text excludes surrounding tool tab/focus metadata. It is an accessibility snapshot, not HTTP bytes, HTML or a DOM serialization.

A text node may contain several cards, so parsing uses exact `DISTRICT N` boundaries across the text-node projection. Chamber completeness requires all 20 even Senate districts or all 80 Assembly districts without duplicates. Accepted calls require the three literal markers `WINNER`, a named subject followed by `wins.`, and `AP race call at`. The exact rendered candidate label is preserved, including abbreviations. A displayed lead remains `uncalled`, including leads with an estimated 100% counted. Unknown card wording rejects the extraction.

Each accepted designation retains the full card narrative, source heading, district, original source observation and literal AP call-time label. The page does not establish the call-time timezone; `mediaCalledAt` remains null rather than fabricating a timestamp. Candidate identifiers and party labels remain unknown when absent from the accessibility tree. These are media calls, separate from certification and serving membership.

Run `.venv-geo/bin/python -m unittest discover -s tools -p test_temporal_media_california.py`. `collect(fetch, offline=True)` retains original observation times and produces `designations`, `raceStatuses`, `stateAudits` and `sourceObservations`. Missing snapshot evidence and validation failures are explicit; they do not establish missing elections or vacant seats.

The acquired Assembly accessibility projection contains all 80 cards: 51 explicit timestamped AP race calls and four separately labeled `UNCONTESTED` statements that explicitly say the named candidate wins while running unopposed. Those four statements are accepted as explicit publisher outcomes, with `publisherOutcomeType: explicit-publisher-uncontested-win`; an uncontested candidate list without the explicit win statement is rejected. They have no call timestamp. The remaining 25 cards display leads without an explicit outcome. Combined with Senate, the observation includes 100 races and 64 explicit publisher outcomes.

Assembly evidence has SHA-256 `0d6bdab1ffd81890f4d3cc09d1590a18fd7db78c6a0d79bf978393fa198a7fdc`, 10,151 bytes, observed at `2026-11-05T05:32:56Z` using the clock after capture. Its acquisition engine is `Playwright.domSnapshot`, producing an accessibility projection. The source identifier `media-california-ap-assembly-cards-ax` remains bound to embed `38133`. No result is inferred from the separate district-picker embed `38145`.
